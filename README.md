# 💬 فضفضة عشوائية

موقع دردشة عشوائية خاصة باللغة العربية — بضغطة زر نوصلك بشخص غريب عشوائي،
تتحدث معه بخصوصية تامة (رسائل 1-1 فورية)، مع زر «التالي» للانتقال لشخص جديد.

> الشعار: «دردشة عشوائية للفضفضة — تحدث مع غرباء بخصوصية تامة»

## التقنيات

- **Node.js + Express** — السيرفر وتقديم الصفحات
- **ws** — رسائل فورية عبر WebSocket + إشعارات المطابقة والحضور
- **better-sqlite3** — قاعدة بيانات SQLite محلية (ملف `data/chat.db`)
- **bcryptjs** — تشفير كلمات المرور
- **express-session** — الجلسات عبر كوكيز httpOnly
- واجهة خام (HTML/CSS/JS) عربية RTL بثيم داكن

## التشغيل محليًا

```bash
cd chat-site
npm install
cp .env.example .env   # ثم عدّل القيم داخله
npm start
```

افتح المتصفح على: http://localhost:3000

وضع التطوير (إعادة تشغيل تلقائية عند تغيير الملفات):

```bash
npm run dev
```

## تغيير اسم الموقع / الرابط

كل النصوص تستخدم متغيرات البيئة — لا حاجة لتعديل الكود:

| المتغير | الوظيفة | الافتراضي |
|---|---|---|
| `SITE_NAME` | اسم الموقع في العناوين والصفحات | فضفضة عشوائية |
| `TAGLINE` | السطر التعريفي | دردشة عشوائية للفضفضة — تحدث مع غرباء بخصوصية تامة |
| `SITE_URL` | الرابط الرسمي (canonical + sitemap) | https://example.com |
| `SESSION_SECRET` | سر تشفير الجلسات — **غيّره في الإنتاج!** | قيمة تجريبية |
| `PORT` | المنفذ | 3000 |

> ⚠️ **مهم قبل النشر:** بدّل `SITE_URL` برابط موقعك الحقيقي (مثال: `https://fadfadasha.com`)
> حتى يعمل `sitemap.xml` و`robots.txt` بشكل صحيح مع قوقل.

```
chat-site/
├── server.js            # السيرفر: API + WebSocket + المطابقة العشوائية

│   ├── app.html         # تطبيق الدردشة
│   ├── css/style.css    # ثيم داكن
│   ├── js/auth.js       # منطق التسجيل/الدخول
│   ├── js/app.js        # منطق الدردشة والمطابقة
│   ├── robots.txt       # (يُحقن فيه SITE_URL تلقائيًا)
│   └── sitemap.xml      # (يُحقن فيه SITE_URL تلقائيًا)
├── data/                # ملف قاعدة البيانات (يُنشأ تلقائيًا)
├── test/smoke.js        # اختبار دخاني شامل
├── Dockerfile
├── README.md
└── DEPLOY.md            # خطوات النشر + الظهور في قوقل
```

## الاختبار

```bash
npm test
```

يشغّل `test/smoke.js` الذي يتحقق من: إقلاع السيرفر، الصفحات، التسجيل/الدخول،
المطابقة العشوائية، إرسال الرسائل عبر WebSocket، الحظر، وقواعد SEO.

## ملاحظات أمنية

- كلمات المرور مشفّرة بـ bcrypt (10 جولات).
- كل محتوى المستخدم يُعرض عبر `textContent` فقط — لا `innerHTML` مع مدخلات.
- حدّ معدل (rate limit) على مسارات التسجيل/الدخول.
- الجلسات بكوكيز `httpOnly`، والسر من متغير البيئة.
- مصادقة WebSocket عبر كوكي الجلسة الموقّع.
